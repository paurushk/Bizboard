# Pilot CSAT survey copy (15.7)

Not a contract. Not GST advice. Human sets the numeric target **before**
seeing scores.

Ask after week 2 of daily use. One respondent per firm (Owner). Score 1–5.

1. I can complete a sale and see the same outstanding on the customer ledger.
2. A purchase bill increases stock and supplier payable together.
3. A sales return / credit note reverses stock, tax, and AR the way I expect.
4. GSTR-1 / GSTR-3B in BizBoard are worksheets I (or my CA) file on the portal.
5. I would pay for this as my primary books for this freeze scope.

Do **not** ask whether BizBoard files GSTN returns, issues a live IRN, runs
payroll, or syncs Tally — those are Table B dark.

Free-text (optional): “What broke this week?” Cluster with
`docs/ops/FEEDBACK_TRIAGE.md`.
